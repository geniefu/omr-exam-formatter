# OMR Exam Formatter｜試題融入式畫卡考卷排版與 AI 自動閱卷技能

專為台灣中小學黑白油印雙面考卷（B4／A4 雙欄）打造的 Antigravity / AI Agent 技能套件。
免買讀卡機、不限 2B 鉛筆，從出版商題庫 Word 檔一鍵轉成「方案 A 試題融入式畫卡考卷」，考後掃描 PDF 即可交由 AI 自動批改並產出單頁 A4 班級成績單與重點複習診斷！

![AI 智慧閱卷 4 步驟流程海報](assets/workflow_poster.png)

## 四步驟教學工作流

1. **線上題庫出題**：使用出版商線上題庫出題，下載 Word（`.docx`）檔。
2. **AI 一鍵排畫卡**：將 Word 檔交給 AI 套用本技能排版成「方案 A 畫卡試題卷」，送交油印印製紙本試卷。
3. **不限筆種作答**：學生使用 **2B 鉛筆、藍筆或黑筆** 皆可直接於試題卷上的畫卡區塗滿作答。
4. **掃描 PDF 自動批改**：將全班作答卷掃描成 PDF 交給 AI，自動完成四角定位校正、OMR 判讀與人工複核，產出標準化單頁 A4 班級成績單（`.xlsx`）。

## 核心特色

### 1. 方案 A 試題融入式畫卡排版（`scripts/convert_exam_omr.py`）
- **正反面錯開防透背**：第 1 面畫卡區置於**頁首**（含 `01～99` 緊湊座號畫卡），第 2 面畫卡區置於**頁尾**（第 2 面頁首留白），避免薄紙油印透背誤判。
- **黑白油印最佳化**：純白底＋純黑線框（零灰底網點干擾）、四角實心定位黑塊（Fiducial Markers）與 `P1`/`P2` 方向標記。
- **題目無損整理**：自動移除原本的作答括號、全卷連續順號（含題組接續編號）、選擇題換行精準對齊第一個字、題組小題獨立成段且題號凸排，完整保留原卷附圖與公式。

### 2. OMR 自動閱卷與單頁 A4 班級成績單（`.xlsx`）
- **全動態 Excel 公式**：自動計算每位學生的選擇成績、合計成績、答對題數／總題數、班級名次與班級平均；缺考學生自動排除不影響平均。
- **各題錯誤率＋螢光筆標記**：於班級平均下方以每行 10 題橫式大字呈現 `題號(錯誤率)`，凡錯誤率達 **50%（含）以上** 自動以螢光黃標記。
- **班級重點複習建議**：結合試題內容與全班常見誤選迷思，於表格最下方自動歸納 4～6 項教學複習重點，單頁 A4 完整列印。
